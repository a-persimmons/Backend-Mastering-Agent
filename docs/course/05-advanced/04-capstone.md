# 毕业项目：生产级 Agent 系统原型

::: tip 本课目标
最终验收是可以独立定位、设计、实现和改进系统；不是声称个人原型已达到企业生产认证。
:::

## 1. 原理与边界

交付 API + runtime + model adapter + tools + context/memory + durable storage + evals + telemetry。按需求选择语言与部署形态。关键非功能需求要量化：成功率、延迟、吞吐、预算、隔离、恢复、成本。安全、权限与副作用是硬约束。

## 2. 贯穿项目中的例子

以企业工单 Agent 为主，也可选择 Coding Agent 或研究 Agent。必须保留真实业务场景和运行时系统两个维度。对每个外部依赖明确 timeout、retry、fallback 与可观测字段。

## 3. 动手实验

完成 V1.0：提交源码、README、架构图、API 契约、至少 50 条评估样本、三组重复压测、三个故障实验、两份 ADR（技术栈与可靠执行）。演示取消、重启恢复、越权拒绝。

先记录基线、环境和失败样本，再做控制变量实验。使用[实验模板](../../guide.md)保存结论。

## 4. 验收标准

评审：功能与效果 25%、运行时可靠性 25%、性能与容量 20%、安全 15%、实验与决策 15%。任何未授权副作用或跨租户泄露必须先修复；分数不是生产认证。

## 5. 定向阅读

- [参考资料](https://www.anthropic.com/research/managed-agents)：对照真实架构边界，说明自己的差距与后续演进。

将阅读内容映射到自己的系统，明确哪些机制可以复用、哪些需要验证。

# 长期记忆：从记录历史到可治理事实

::: tip 本课目标
长期记忆不是把所有对话向量化。关键是写入、检索、更新和删除的生命周期。
:::

## 1. 原理与边界

情景记录保留原始事件；语义记忆保存可复用事实及来源、时间、置信度、租户。写入前检测敏感性和重复；冲突事实标记失效或版本化；查询时做 ACL、时效与相关性过滤。用户纠正优先于旧推断。

## 2. 贯穿项目中的例子

用户先说数据库是 MySQL 5.7，后更正为 8.0。记忆记录 valid_from、valid_to、source_event_id，当前检索只返回有效事实；历史审计仍能追溯。

## 3. 动手实验

实现 SQLite 事实表与检索接口，注入重复事实、冲突事实、过期事实、跨租户查询。评估 relevant memory recall、错误记忆率和污染率。

先建立可运行基线，保存输入、日志、版本与失败样本，再进行对照实验。输出记录可采用[实验模板](../../guide.md)。

## 4. 验收标准

能够解释何时不用长期记忆；删除后检索不可返回，跨租户无泄露，冲突更新测试通过。

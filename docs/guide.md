# 如何学习这门课

## 每课固定闭环

1. 明确问题：没有这个模块会发生什么？
2. 建立模型：画出输入、状态、输出和失败路径。
3. 实现最小版本：先写 deterministic fake，后接真实模型。
4. 制造故障：一次改变一个变量，保存日志、指标和样本。
5. 做决策：比较替代方案、边界和成本。
6. 验收：不看教程也能解释、实现、排查。

## 自评等级

| 等级 | 证据 |
| --- | --- |
| L1 知道 | 能描述概念 |
| L2 理解 | 能解释机制及反例 |
| L3 实现 | 有测试、可运行代码 |
| L4 求解 | 有问题假设、基线、实验结果、决策记录 |

阶段 1–2 目标主要 L2/L3；阶段 3–4 核心模块达到 L3 并尝试 L4；阶段 5 以 L4 证据为主。

## 实验记录模板

```text
问题 / 影响：
基线 / 环境 / 版本：
假设（按证据排序）：
单一变量：
数据集 / 工作负载：
指标与停止条件：
结果（含失败样本）：
结论与剩余不确定性：
回滚方案：
```

使用 Git tag 或独立分支保留每阶段结果。模型输出不是确定性真值；固定测试集、模型版本、参数并进行重复试验。练习给出的阈值是教学目标，不是行业 SLA。

## 阅读顺序

先读课内正文，再按指定的官方章节或案例阅读，最后完成实践。不要把收集链接当作学习完成。已有经验者优先做验收题。
